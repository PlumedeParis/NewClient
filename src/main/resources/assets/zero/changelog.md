## 2.4.0
- **Updater**: ZERØ checks GitHub for new versions when the game starts and asks you: update now (closes, updates and reopens Minecraft), on next launch, later, or skip this version
- Downloads are checked with a SHA-256 fingerprint before they are installed
- This "What's new" screen after every update
- Client → General → Updates turns update checks off

## 2.3.0
- Much less lag: ZERØ's cost per tick is 3 to 5 times lower, worst stutter 280 ms → about 28 ms
- Chunk re-scans are spread out and only happen for changes that matter
- SusChunk skips empty parts of chunks (11 ms → 0.3 ms per chunk)
- SafeMiner's path search is capped at 0.7 ms per tick

## 2.2.0
- **Base confidence**: one percentage per place with the reasons (89% Base ✔ spawner ✔ 5 storage...)
- Smooth vector font in the GUI, HUD and pop-ups
- Themes: Zero, Midnight, Neon, Ember, Aurora, Gold, Mono, Custom
- A placed spawner no longer makes a base look like a dungeon
